# ops — the tools and routines that run it

One job: the boring parts, written down once so they never have to be re-explained.

## Layout
```
ops/
  tools.md       every tool you pay for, what it's for, where the login lives (a password manager, never here)
  routines.md    the repeating jobs: daily, weekly, monthly, and who or what runs them
  inbox/         files you haven't placed yet. Empty it weekly.
```

## Inputs
- Reference (every task): `../_shared/rules.md`

Do NOT load: `inbox/` unless asked to sort it.

## Rules
- No secrets in this folder. `tools.md` says where a login lives, never what it is.
- A routine that hasn't repeated three times is a task, not a routine. Don't write it up yet.

## Human check
Open `inbox/` every Friday. Anything still there after two weeks either gets a home or gets deleted.
