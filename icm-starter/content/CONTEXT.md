# content — what we publish

One job: turn ideas into posts, in your voice, and keep the results next to them.

## Layout
```
content/
  ideas/        one file per idea, named by the hook
  drafts/       scripts and posts being written
  posted/       what shipped, with the link and the numbers
```

A piece moves folder as it moves stage. The folder it sits in IS its status. No status column anywhere else.

## Inputs
- Working (this task): the one file in `ideas/` or `drafts/` you were sent to
- Reference (every task): `../_shared/voice.md`, `../business/avatar.md`

Do NOT load: `posted/` in bulk, `clients/`, `money/`.

## Process
1. Read the voice file, then the one working file.
2. Draft. Keep the hook the idea file already has unless asked to change it.
3. Save back into the same file. Never make a second copy.

## Human check
Read the draft as if it were on your phone. If it doesn't sound like you, it isn't done.
