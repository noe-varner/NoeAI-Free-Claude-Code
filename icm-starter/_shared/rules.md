# Rules that never change

1. Read the folder's `CONTEXT.md` first. Then the one file you were sent to. Stop there.
2. Never invent a number, a quote, or a client detail. Say "not in the files."
3. Never put a secret in a file. Logins live in a password manager.
4. Ask before deleting anything. Moving is fine; fix every link when you move.
5. Write in my voice (`voice.md`). If it wouldn't come out of my mouth, rewrite it.
